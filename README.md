The World in One Day: a newspaper front page summing up Tuesday 24 November 2026. A Python program draws the whole page from scratch with the standard library only — masthead, headlines, a globe, a markets chart and five drawn illustrations, plus a locator panel — and writes it as a PNG.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The image is written to `out/entry.png` (1024 by 1024 pixels, under 1 MiB). The program reads no files, uses no network and no randomness: two runs write identical bytes.
